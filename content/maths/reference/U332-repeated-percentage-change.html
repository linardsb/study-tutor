Repeated percentage change

  1. First change: find the percentage, add or take off. Write the new amount.
  2. Second change on the new amount, never the original.
  3. One line per year, running total.
  4. Calculator: × the multiplier each time. £200 × 1.1 × 1.1 = £242.

£8000 car losing 10% a year: 8000 → 7200 → 6480 after 2 years.

Interest

Simple: same each year. 5% of £400 = £20, so £440 after 2 years.
Compound: on the new total, 400 → 420 → 441.

Mistakes to avoid

  • Adding the percentages: 10% then 10% is not 20%.
  • Second change taken off the original.
