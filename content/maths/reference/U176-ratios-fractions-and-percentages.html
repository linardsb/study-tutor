Ratios, fractions and percentages

  1. Fraction → decimal: top ÷ bottom.
  2. Decimal → %: × 100. % → decimal: ÷ 100.
  3. % → fraction: over 100, simplify.
  4. Decimal → fraction: place value, simplify.
  5. Ratio 3:2 → the first part is 3/5 of the whole.
  6. To order: all to decimals first.

3/8 = 0.375 = 37.5%.   0.45 = 45/100 = 9/20.

1/2 = 0.5 = 50%. 1/4 = 0.25 = 25%. 1/5 = 0.2 = 20%. 1/8 = 0.125 = 12.5%.

Mistakes to avoid

  • Copying the digits: 3/8 is not 0.38.
  • Moving one place instead of two: 0.5 is 50%, not 5%.
