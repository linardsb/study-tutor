Probability trees

  1. One branch per outcome of the first event, probability on each.
  2. From each end, the branches for the second event.
  3. Each set of branches adds to 1.
  4. Multiply along a branch for one path.
  5. Add the paths that fit the question.

3 red, 2 blue, put back: one of each = 3/5 × 2/5 + 2/5 × 3/5 = 12/25.

Without replacement

Bottom number drops by 1. The colour you took drops by 1 on top: 3/5 × 2/4 = 3/10.

Mistakes to avoid

  • Adding along a branch instead of multiplying.
  • Keeping the same fractions when the first item is not put back.
