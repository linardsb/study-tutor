Simplifying ratio

  1. Same units first, then drop the unit.
  2. Find the highest common factor (the biggest number that divides into every part).
  3. Divide every part by it.
  4. Check nothing else divides all the parts.

2 m : 50 cm → 200:50 → 4:1.   8:12:20 → 2:3:5.

The form 1:n

Divide both parts by the first number. Decimals allowed: 4:10 → 1:2.5.

Mistakes to avoid

  • Simplifying before the units match.
  • Dividing only one part.
