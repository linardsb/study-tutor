Probability trees

By the end you can draw a tree for two events and find the probability of any outcome.

A tree diagram (a drawing where each branch is one outcome) shows two events in a row. A bag holds 3 red and 2 blue counters. You take one, put it back, take another.

Multiply along a branch. The four ends add up to 1. That is the check.

Worked example

The bag above, with replacement. Find the probability of one red and one blue.

Step 1, first pick: red 3/5, blue 2/5.
Step 2, second pick: the same fractions, because the counter went back.
Step 3, check: 3/5 + 2/5 = 1 on every set of branches.
Step 4, multiply along: red then blue is 3/5 × 2/5 = 6/25, and blue then red is 2/5 × 3/5 = 6/25.
Step 5, two paths fit, so add: 6/25 + 6/25 = 12/25.

Same bag, without replacement. Find the probability of two reds. Step 2 changes: after one red, 2 reds sit in 4 counters, so the second is 2/4. Step 4, 3/5 × 2/4 = 6/20 = 3/10.

The method

  1. Draw a branch for each outcome of the first event. Write its probability on it.
  2. From the end of each branch, draw the branches for the second event.
  3. Check each set of branches adds to 1.
  4. Multiply along the branches to get the probability of one path.
  5. If more than one path fits, add those paths together.

With replacement the second set of fractions matches the first. Without replacement the bottom number drops by 1, and so does the top number of the colour you took.

Why do you multiply along a branch instead of adding?

Along a branch both things have to happen. The second event takes a fraction of what the first one left. A fraction of a fraction is smaller. Adding would make it bigger.

Another way to see it

Draw the 25 equally likely pairs as a grid, 5 columns by 5 rows.

Nine squares are red then red, four are blue then blue, twelve are one of each.

The grid stops matching without replacement. The second pick then has four options, so the square is not 5 by 5.

Watch out

Along a branch you multiply. Across the ends you add. Adding along a branch loses the most marks.

Read the question for "put back" or "not replaced". That decides the second set of fractions.

Try it

Answer from memory, no calculator. Write fractions like 3/5 or decimals like 0.6. The working appears only after you check.

1. A fair coin is flipped twice. What is the probability of two heads? The first step is done. Finish it.

Heads is 1/2 each time. …

Multiply along the branch: 1/2 × 1/2.

Heads is 1/2 each time. Along the branch: 1/2 × 1/2 = 1/4.

2. A bag has 3 red and 2 blue counters. One is taken, put back, and another taken. What is the probability both are blue? The first step is done. Finish it.

The counter goes back, so blue is 2/5 both times. …

Multiply along the branch: 2/5 × 2/5.

The counter goes back, so blue is 2/5 both times. Along the branch: 2/5 × 2/5 = 4/25. As a decimal that is 0.16.

3. The probability it rains on any day is 0.3. What is the probability it rains on exactly one of Saturday and Sunday?

Not raining is 0.7. Two paths fit: wet then dry, and dry then wet.

Not raining is 0.7. Rain then dry: 0.3 × 0.7 = 0.21. Dry then rain: 0.7 × 0.3 = 0.21. Add the two paths: 0.42.

4. A spinner has 5 equal sections: 2 red and 3 green. It is spun once. What is the probability it does not land on red?

One spin, so there is no branch to multiply along. Count the sections.

One event, so no tree is needed. Not red is the 3 green sections out of 5, which is 3/5. You could also do 1 − 2/5 = 3/5.

5. A bag has 4 green and 1 yellow sweet. Two are taken without replacement. Someone writes green 4/5, then green 4/5 again, then multiplies to get 16/25. Which step number did they get wrong first?

Read the method list. Which step writes the second set of branches?

Step 2 writes the second set of branches. Without replacement one sweet is gone. So the second green is 3 out of 4, not 4 out of 5. Done properly: 4/5 × 3/4 = 12/20 = 3/5.
