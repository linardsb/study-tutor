Equations of parallel lines

By the end you can spot parallel lines from their equations, and write the equation of a parallel line.

Parallel lines (lines that never meet) have the same steepness. In y = mx + c that means the same m. Only c, where the line crosses the y-axis, is different.

Both lines go up 2 for every 1 across, so m = 2 for both. They cross the y-axis at different places.

Worked example

Write the equation of the line parallel to y = 2x + 1 that passes through (3, 10).
Step 1, it is already in the form y = mx + c.
Step 2, read m: the number in front of x is 2.
Step 4, keep m and leave c open: y = 2x + c.
Step 5, put in x = 3 and y = 10: 10 = 2 × 3 + c, so 10 = 6 + c and c = 4.
The line is y = 2x + 4.

Is y = 3x + 2 parallel to 2y = 6x − 4?
Step 1, rearrange the second one. Divide everything by 2: y = 3x − 2.
Step 2, read m from each: 3 and 3.
Step 3, same m, so yes, parallel.

The method

  1. Write each line as y = mx + c. Rearrange first if y is not on its own.
  2. Read m, the number in front of x, minus sign included.
  3. Same m means parallel. Different m means not parallel.
  4. To write a parallel line, keep m and change c.
  5. Through a point? Put its x and y into y = mx + c, then solve for c.
Why does the number in front of x decide whether two lines are parallel?

m is how far y goes up for each 1 across. Same m, same climb, so the gap never changes. c only slides the line up or down.

Another way to see it

Read each line as a table. y = 2x + 1 gives 1, 3, 5, 7. y = 2x − 3 gives −3, −1, 1, 3. Both jump by 2 and the gap stays 4.

Same jump of 2 in each row.

The table stops matching for a line like 2y = 4x + 6. Rearrange to y = 2x + 3 first.

Watch out

Rearrange before you read m. In 2y = 4x + 6 the gradient is 2, not 4, because y = 2x + 3.

y = 3x + 2 and y = −3x + 2 are not parallel. A matching c means nothing. m has to match.

Try it

Answer from memory, no calculator. Write equations like y=4x+7. The working appears only after you check.

1. Write the equation of a line parallel to y = 4x + 1 that crosses the y-axis at 7. The first steps are done.

Step 2: m = 4. Step 4: keep m, so y = 4x + c. Crossing the y-axis at 7 means c = 7. So the line is …

Put c = 7 into y = 4x + c.

Step 2: m = 4. Step 4: keep m, so y = 4x + c. Crossing the y-axis at 7 means c = 7. So the line is y = 4x + 7.

2. Write the equation of the line parallel to y = 2x − 7 that passes through (3, 10). The first steps are done.

Step 2: m = 2. Step 4: keep m, so y = 2x + c. Step 5: put in x = 3 and y = 10: 10 = 2 × 3 + c. …

2 × 3 is 6. What has to be added to 6 to make 10?

Step 2: m = 2. Step 4: keep m, so y = 2x + c. Step 5: put in x = 3 and y = 10: 10 = 2 × 3 + c. So 10 = 6 + c and c = 4. The line is y = 2x + 4.

3. Which line is parallel to y = 5x − 2? (a) y = 2x − 5, (b) y = 5x + 3, (c) y = −5x − 2. Type a, b or c.

Read the number in front of x in each one.

Gradients: 2, 5 and −5. Only (b) has gradient 5, the same as y = 5x − 2.

4. The graph shows a line. Which equation is parallel to it: (a) y = 3x − 4, (b) y = 2x + 3, (c) y = −3x + 2? Type a, b or c.

How far does the line go up for each 1 across? That is m.

This is identifying graphs, reading a graph. From (0, 2) to (1, 5) the line goes up 3 for 1 across, so m = 3. It crosses at 2, so the line is y = 3x + 2. Parallel needs m = 3: (a) y = 3x − 4.

5. Phone plan A costs C = 3n + 10 pounds a month, where n is the gigabytes used. Plan B charges the same per gigabyte but £5 more each month. Write the equation for plan B.

Same price per gigabyte means the same m. Only the monthly charge, c, moves.

Same price per gigabyte means the same gradient, 3. £5 more a month moves c from 10 to 15. C = 3n + 15. On a graph the two plans are parallel lines.
