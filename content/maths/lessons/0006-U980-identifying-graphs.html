Identifying graphs

By the end you can match an equation to its graph, and read gradient and intercept by eye.

Four shapes cover nearly every Foundation question. The highest power of x (the small number above the x) tells you which one.

Straight line, U shape, S shape, two curves in opposite corners. Learn these by heart.

Worked example

Which graph is y = 3x − 2?
Step 1, highest power of x: just x, to the power 1.
Step 2, so the graph is a straight line.
Step 4, written as y = mx + c: m = 3 and c = −2.
Step 5, m is positive, so it slopes up from left to right.
Pick the line that slopes up and crosses the y-axis at −2.

A line crosses the y-axis at 4 and goes down 2 for every 1 across. Write its equation.
Step 4, it crosses at 4, so c = 4.
Step 6, down 2 for 1 across, so m = −2.
The equation is y = −2x + 4.

The method

  1. Find the highest power of x in the equation.
  2. Plain x: a straight line. x²: a U. x³: an S. 1/x: two curves that avoid the axes.
  3. A minus in front of x² turns the U upside down. A minus before x³ flips the S.
  4. Straight line: y = mx + c. m is the gradient (steepness). c is the y-intercept (where it crosses).
  5. Positive m slopes up from left to right. Negative m slopes down.
  6. To read m off a graph, count: up how many for one step across.

Check: put a point's x into the equation and see if the y matches.

Why is the gradient of y = 7 − 3x equal to −3, and not 3?

The minus sign belongs to the 3, not the 7. Rewrite it as y = −3x + 7 and the m is in plain sight. As x goes up by 1, y drops by 3, so the line slopes down.

Another way to see it

A table of values works too. For y = 2x + 1:

y climbs by 2 each time x climbs by 1. That steady 2 is the gradient. x = 0 gives the intercept.

The steady climb stops for a curve. In a table for y = x² the jumps grow, so a constant step means a straight line.

Watch out

The gradient is the number in front of x, minus sign included. In y = 7 − 3x it is −3.

A U shape means x², not x. A curve is never y = mx + c.

Try it

Answer from memory, no calculator. Write equations like y=4x+1. The working appears only after you check.

1. This line is y = mx + c. Write the part after the equals sign, like 4x+1. The first steps are done.

Read c: the line crosses the y-axis at 3. Read m: it goes up 2 for every 1 across, so m = 2. …

Write the m, then the x, then the c.

Read c: the line crosses the y-axis at 3. Read m: it goes up 2 for every 1 across, so m = 2. Equation: y = 2x + 3.

2. This line is y = mx + c. Write the part after the equals sign, like 4x+1. The first step is done.

Read c: the line crosses the y-axis at 4. …

The line falls, so m is negative. Count how far it drops for one step across.

Read c: the line crosses the y-axis at 4. It falls from left to right, so m is negative. It drops 2 for every 1 across, so m = −2. Equation: y = −2x + 4.

3. This graph is one of y = x², y = x³ or y = 1/x. What is the highest power of x in its equation?

Which of the four shapes is a U, and what power goes with it?

A U shape comes from x², so the highest power is 2. Both arms rise, which x³ never does.

4. The solid line is y = 3x + 1. The dashed line is parallel to it and crosses the y-axis at −4. Write the dashed line as mx + c, like 4x+1.

Parallel lines have the same gradient. Only the c changes.

Parallel means the same steepness, so m stays 3. The new line crosses at −4, so c = −4. Equation: y = 3x − 4.

5. A taxi charges £3 to start, then £2 for every mile. The graph shows cost against miles. What is its gradient?

The gradient is what the cost does for each extra mile.

Cost = 2 × miles + 3. The gradient is the number in front of miles, which is 2. The £3 is the intercept.
