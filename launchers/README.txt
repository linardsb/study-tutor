Study tutor

1. Extract the zip first. You should have a folder called StudyTutor.
2. Mac: open Start.command. Windows: open Start.bat.
3. A black window opens, then your browser opens on the tutor's page.
4. When you are done, close the browser tab, then close the black window to stop.

Mac: if it says the file cannot be verified, click Done. Open System Settings, click Privacy & Security, scroll down to Security and click Open Anyway. Then open Start.command again.

Windows: if it says Windows protected your PC, click More info, then Run anyway.
